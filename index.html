📋 Guide rapide
1. Créez un projet sur supabase.com (gratuit)
2. SQL Editor → copiez le fichier supabase/schema.sql → Run
3. Settings → API → copiez Project URL + anon key
4. Si erreur RLS → SQL Editor → ALTER TABLE clients DISABLE ROW LEVEL SECURITY; (pour chaque table)
