📋 Guide d'installation
1. Créer un projet Supabase
Allez sur supabase.com → New Project → gratuit
2. Exécuter le schéma SQL
Ouvrez le fichier supabase/schema.sql → copiez dans SQL Editor → Run
3. Récupérer vos clés
Settings → API → copiez Project URL et anon key ci-dessus
4. Lancer le backend (optionnel)
pip install -r requirements.txt
uvicorn main:app --reload
5. Tester
Cliquez "Tester la connexion" ci-dessus ✅
